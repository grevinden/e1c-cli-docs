## Режим агента

Конфигуратор может работать в режиме агента — SSH/SFTP-сервер для удаленного управления (загрузка/выгрузка конфигурации, работа с файлами).

| Команда | Описание |
| --- | --- |
| `/AgentMode` | Включить режим агента. При наличии игнорируются `/DisableStartupMessages` и `/DisableStartupDialogs` |
| `/AgentPort <порт>` | Порт SSH-сервера (по умолчанию **1543**) |
| `/AgentListenAddress <адрес>` | Прослушиваемый IP-адрес (по умолчанию **127.0.0.1**) |
| `/AgentSSHHostKey <приватный ключ>` | Путь к закрытому ключу хоста. Если не указан — нужна `/AgentSSHHostKeyAuto`; если ни того, ни другого — запуск в режиме агента невозможен |
| `/AgentSSHHostKeyAuto` | Использовать ключ в стандартном расположении (см. ниже). Если файла нет — создается RSA-ключ 2048 бит |
| `/AgentBaseDir <каталог>` | Рабочий каталог SFTP-сервера и команд загрузки/выгрузки конфигурации |

Стандартные расположения:

| ОС | Ключ хоста | Рабочий каталог |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\1C\1cv8\host\_id` | `%LOCALAPPDATA%\1C\1cv8\<UUID ИБ>\sftp` |
| Linux | `~/.1cv8/1C/1cv8/host\_id` | `~/.1cv8/1C/1cv8/<UUID ИБ>/sftp` |
| macOS | `~/.1cv8/1C/1cv8/host\_id` | `~/.1cv8/1C/1cv8/<UUID ИБ>/sftp` |

Подробнее о работе конфигуратора в режиме агента — в официальной документации («Дополнительные утилиты»).

## Прочие команды пакетного режима

| Команда | Описание |
| --- | --- |
| `/Visible` | Сделать исполнение пакетной команды видимым: открывается окно заставки. В режиме агента — информационное окно на экране |
| `/RunEnterprise` | Запустить «1С:Предприятие» после исполнения пакетной команды. После команды может идти дополнительная командная строка (в кавычках, внутренние кавычки удвоены) — ее параметры используются вместо параметров текущей сессии |
| `/ConvertFiles <имя файла\|путь>` | Пакетная конвертация файлов 1С:Предприятия 8.x. Файл или каталог (рекурсивно). Файлы должны быть доступны для записи: для одного файла недоступность — ошибка; в режиме каталога недоступные пропускаются без сообщений. Нужен запущенный Конфигуратор с открытой конфигурацией; параметры ИБ и авторизации — стандартными параметрами командной строки (без них — запросы) |
| `/DumpResult <имя файла>` | Записать результат работы конфигуратора в файл (число; 0 — успех) |
