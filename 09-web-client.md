# Командная строка веб-клиента

← [К оглавлению](README.md) · Назад: [Строка соединения](08-connection-string.md) · Дальше: [Мобильная версия](10-mobile-version.md)

Параметры веб-клиента передаются в **URL запуска** (query-строка). Кроме того, особая навигационная ссылка в URL открывает форму стандартной функции.

## Открытие формы стандартной функции

Навигационная ссылка формата `#e1cib/system/<stdFuncName>` в URL запуска открывает форму указанной стандартной функции (только при запуске веб-клиента).

Пример:

```
http://localhost/InfoBase/?mainWindowMode=Workplace&DisableHomePageForms#e1cib/system/AnalyticsSystemManagement
```

Поддерживаемые стандартные функции:

| `<stdFuncName>` | Стандартная функция |
| --- | --- |
| `ActiveUsers` | Активные пользователи |
| `AdditionalAuthenticationSettings` | Дополнительные настройки аутентификации |
| `AnalyticsSystemManagement` | Управление системой аналитики |
| `AuthenticationLocks` | Блокировка аутентификации |
| `CollaborationSystemManagement` | Управление системой взаимодействия |
| `ConfigurationExtensionsManagement` | Управление расширениями конфигурации |
| `ConfigurationLicense` | Лицензирование конфигураций |
| `DataBaseCopiesManagement` | Управление копиями базы данных |
| `DataChangeHistory` | История изменения данных |
| `DeleteMarkedObjects` | Удаление помеченных объектов |
| `DocumentsPosting` | Проведение документов |
| `ErrorProcessingSettings` | Управление настройками обработки ошибок |
| `EventLog` | Журнал регистрации |
| `EventLogSettings` | Настройка журнала регистрации |
| `ExternalDataSourcesManagement` | Управление внешними источниками данных |
| `FindByReference` | Поиск ссылок на объекты |
| `FullTextSearchManagement` | Управление полнотекстовым поиском |
| `InfobaseParameters` | Параметры информационной базы |
| `InfobaseRegionalSettings` | Региональные установки информационной базы |
| `IntegrationServicesManagment` | Управление сервисами интеграции |
| `LicenseAcquisition` | Получение лицензии |
| `MobileAppBuildService` | Сервис сборки мобильных приложений |
| `MobileAppBuilderServiceLoader` | Загрузчик сервиса сборки мобильных приложений |
| `ServersManagement` | Управление серверами |
| `TotalsManagement` | Управление итогами |
| `UserList` | Пользователи |

## Параметры URL

### Подключение и аутентификация

| Параметр | Описание |
| --- | --- |
| `N=<имя>` | Имя пользователя (как в списке пользователей Конфигуратора) |
| `P=<пароль>` | Пароль пользователя из `N` (можно опустить, если пароль не задан) |
| `WA<режим>` | Аутентификация ОС при запуске: `+` — обязательна (по умолчанию, если `/WA` не указан); `–` — запрещена |
| `OIDA<режим>` | Сквозная аутентификация через OpenID-провайдера (тонкий и веб-клиенты). Провайдер задаётся в `default.vrd` публикации. `+` — использовать (по умолчанию); `–` — не использовать. При интерактивной аутентификации (первое обращение / истёк срок) показывается диалог ввода имени и пароля. Имя пользователя должно совпадать с именем в базе OpenID-провайдера |
| `OidcSelectedProvider` | Имя настроенного провайдера OpenID Connect для аутентификации |
| `Authoff` | Операция OpenID logout (завершение сеанса) вне зависимости от дальнейшего метода аутентификации |
| `AccessToken` | JWT для аутентификации пользователя |
| `UC=<код доступа>` | Установка соединения с заблокированной базой: если при блокировке задан непустой код доступа — указать его здесь |

### Интерфейс и режимы

| Параметр | Описание |
| --- | --- |
| `MainWindowMode=<режим>` | Режим основного окна: `Normal` — обычный; `Workplace` — рабочее место; `EmbeddedWorkplace` — встроенное рабочее место (встраивание в сторонний сайт); `FullscreenWorkplace` — полноэкранное рабочее место; `Kiosk` — киоск |
| `ProgressiveWebApplicationName=<название>` | Наименование PWA, устанавливаемого из веб-клиента (также задаётся в `default.vrd`) |
| `DisableHomePageForms` | Запрет открытия форм начальной страницы прикладного решения |
| `DisableStartupMessages` | Подавление сообщения «Конфигурация базы данных не соответствует сохраненной конфигурации. Продолжить?» |
| `DisableUnrecoverableErrorMessage` | Специальное поведение при невосстановимой ошибке: окно не показывается; отчёт отправляется (если настроена автоотправка и ≤ 5 Мбайт); вкладка переходит на `about:blank`. Рекомендуется для окружений без пользователя, реагирующего на ошибку |
| `TechnicalSpecialistMode` | Включение команды главного меню «Функции для технического специалиста» |
| `DisplayPerformance` | Отображение числа вызовов сервера и объёма данных (отправка/приём) |
| `iTaxi` | Запуск в режиме интерфейса Такси |
| `itdi` | Игнорируется; запуск в режиме Такси |
| `isdi` | Игнорируется; запуск в режиме Такси |
| `SYSTEMWEBCLIENTSTAT` | Накопление статистики использования веб-клиента (для специалистов фирмы «1С») |

### Локализация и соединение

| Параметр | Описание |
| --- | --- |
| `L=<код языка>` | Код языка интерфейса платформы |
| `VL=<код локализации>` | Код локализации сеанса (форматирование Число/Дата, `ЧислоПрописью()`, `ПредставлениеПериода()`) |
| `O=<скорость>` | Скорость соединения: `Normal` — обычная; `Low` — низкая |
| `C=<строка>` | Передача параметра в прикладное решение |
| `Z=<реквизит 1>,<реквизит 2>,...` | Установка разделителей при запуске |

### Отладка и тестирование

| Параметр | Описание |
| --- | --- |
| `Debug=[<mode>[,attach]]` | Протокол отладки (`tcp` или `http`) и признак `attach` (автоподключение предметов отладки к серверу отладки; только для HTTP). Без параметра — TCP/IP |
| `DebuggerURL=<URL>` | Отладчик для подключения сразу после запуска: для TCP/IP — URL отладчика (протокол, компьютер, порт); для HTTP — URL сервера отладки |
| `TestClient` | Запуск в режиме клиента тестирования |
| `TestClientID=<идентификатор>` | Идентификатор экземпляра веб-клиента для менеджера тестирования. Не указан или дублируется — выбирается произвольно |
| `UsePrivilegedMode` | Привилегированный режим (нужны административные права; журнал регистрации фиксирует установку/отказ) |
