## Параметры подключения

| Команда | Описание |
| --- | --- |
| `/F <каталог>` | Каталог, в котором расположен файл базы данных 1Cv8.1CD (файловый вариант) |
| `/S <адрес>` | Адрес базы на сервере «1С:Предприятия»: `<компьютер>/<ссылочное имя ИБ>`. Разделитель — прямой слеш (любая ОС) или обратный (только Windows); либо весь адрес в кавычках: `server-pc/ibName`, `server-pc\ibName`, `"server-pc\ibName"` |
| `/IBName <имя ИБ>` | Запуск базы по имени из списка информационных баз. Если таких баз несколько — запуск прекращается с ошибкой. Кавычки в имени удваиваются: `База ""СтройТоргВсе""` |
| `/IBConnectionString` | Строка соединения целиком (в виде, который возвращает СтрокаСоединенияИнформационнойБазы()). Части строки могут быть переопределены параметрами, указанными **после** него. Строка содержит кавычки — возьмите её целиком в кавычки, внутренние удвоите. Формат — [здесь](08-connection-string.md) |
| `/WS <url>` | Строка ws-соединения |
| `/O<скорость>` | Скорость соединения (тонкий клиент): `Normal` (по умолчанию), `Low` |
| `/TComp [-None\|-Deflate\|-SDC\|-lz4\|-zstd]` | Сжатие трафика между сервером и тонким клиентом: `-None` — выключено; `-Deflate` — стандартное HTTP-сжатие; `-SDC` — собственный алгоритм; `-lz4` — LZ4; `-zstd` — Zstandard (по умолчанию) |
| `UsePrivilegedMode` | Запуск клиента в привилегированном режиме. Разрешен пользователю с административными правами; установка (или отказ) фиксируется в журнале регистрации |
| `/SLev<уровень>` | Уровень защищенности соединения с сервером (не для тонкого клиента): `0` — незащищенное; `1` — защищенное при аутентификации; `2` — защищенное весь сеанс. Без значения — эквивалентно `0` |
| `/Z "<реквизит 1>,<реквизит 2>,...,<реквизит N>"` | Установка значений разделителей при запуске клиентского приложения |

Дополнительные параметры строки соединения в режиме тонкого клиента: `wsn` (пользователь веб-сервера), `wsp` (пароль веб-сервера), `wspauto` (автонастройки прокси), `wspsrv` (адрес прокси), `wspport` (порт прокси), `wspuser` / `wsppwd` (аутентификация прокси).

## Аутентификация

| Команда | Описание |
| --- | --- |
| `/N<имя>` | Имя пользователя (как в списке пользователей Конфигуратора) |
| `/P<пароль>` | Пароль пользователя из `/N`; можно опустить, если у пользователя нет пароля |
| `/ModifyPassword <пароль>` | Только совместно с `/N` и `/P`: установить пользователю из `/N` новый пароль. Если пароль в `/P` корректен — пользователь аутентифицируется, пароль меняется, сеанс продолжается |
| `/WA<режим>` | Аутентификация ОС при старте «1С:Предприятия»: `+` — обязательна (подразумевается, если `/WA` не указан), `-` — запрещена |
| `/WSA<режим>` | Аутентификация ОС на веб-сервере: `+` — принудительная (по умолчанию), `-` — запрещена |
| `/WSN<имя>` | Имя пользователя ОС для аутентификации на веб-сервере (при `/WSA+`); пароль — в `/WSP` |
| `/WSP<пароль>` | Пароль пользователя из `/WSN` |
| `/NoProxy` | Запретить использование прокси (только ws-соединение) |
| `/Proxy -PSrv <адрес> -PPort <порт> [-PUser <имя> [-PPwd <пароль>]]` | Явные настройки прокси, игнорируя умолчания (только ws-соединение) |
| `/OIDA<режим>` | Сквозная аутентификация через OpenID-провайдера (адрес — в default.vrd публикации ИБ) для тонкого и веб-клиентов: `+` — использовать (по умолчанию), `-` — не использовать. Если провайдер требует интерактивного входа — показывается диалог. Пользователь ИБ должен совпадать по имени с пользователем ИБ провайдера |
| `/AccessToken` | Указать JWT для аутентификации пользователя |
| `/Authoff` | OpenID logout (завершение сеанса) для протоколов OpenID и OpenID Connect; выполняется независимо от дальнейшего метода аутентификации |
| `/SAOnRestart` | При перезапуске клиента из данного сеанса обязательно запрашивать имя и пароль (по умолчанию пароль не запрашивается). Не используется в тонком клиенте |
| `/ResetSavedAuth` | Удалить из хранилища сохраненный токен для повторного входа и имена всех запомненных пользователей, аутентифицировавшихся с этого компьютера |

## Определение режима запуска

| Команда | Описание |
| --- | --- |
| `/AppAutoCheckVersion<режим>` | Автоматический подбор версии под каждую базу: `+` — выполнять (по умолчанию), `-` — не выполнять. Алгоритм: версия определяется по параметру Version файла \*.v8i (файловый вариант) или по ответу сервера (клиент-серверный). Для 8.0/8.1 — запуск соответствующего исполняемого файла (для 8.0 параметр DESIGNER заменяется на CONFIG). Для 8.2+: при полном номере версии — поиск установленной (InstalledLocation) или дистрибутива (DistributiveLocation), установка при необходимости; при неполном — подбор среди DefaultVersion, максимум установленных и доступных к установке |
| `/AppAutoCheckMode` | Автоматическое определение приложения по данным ИБ (основной режим запуска конфигурации и режим пользователя). Если определенный режим не соответствует запущенному клиенту, а у пользователя есть право на нужный клиент — перезапуск нужного клиента той же версии |
| `/RunModeOrdinaryApplication` | Запуск толстого клиента в обычном режиме независимо от настроек конфигурации и пользователя (не для тонкого клиента) |
| `/RunModeManagedApplication` | Запуск толстого клиента в режиме управляемого приложения с учетом настройки «Основной режим запуска» в списке ИБ: «Выбирать автоматически»/«Тонкий клиент» — тонкий клиент; «Веб-клиент» — веб-клиент; «Толстый клиент» — толстый клиент в управляемом режиме. Отключает автоподбор клиента |
| `/AppArch <разрядность>` | Разрядность клиента: `x86` — только 32-бит; `x86_prt` — преимущественно 32-бит (по умолчанию); `x86_64` — только 64-бит; `x86_64_prt` — преимущественно 64-бит |
| `/MainWindowMode <режим>` | Режим основного окна: `Normal` — обычный; `Workplace` — рабочее место; `EmbeddedWorkplace` — встроенное рабочее место (встраивание веб-клиента в сторонний сайт); `FullscreenWorkplace` — полноэкранное рабочее место; `Kiosk` — киоск |

## Сертификаты и TLS

### /HttpsCert — источник клиентского сертификата

```
/HttpsCert [-windows] [-linux] [-macos] [-recent] [-auto] [-choose] [-file <путь>] [-pwd <пароль>] [-none]
```

| Параметр | Описание |
| --- | --- |
| `-windows` | Сертификат из системного хранилища Windows (игнорируется при `-file` или `-none`) |
| `-linux` | Сертификат из специального каталога Linux (игнорируется при `-file` или `-none`) |
| `-macos` | Сертификат из системного хранилища macOS (игнорируется при `-file` или `-none`) |
| `-recent` | Использовать ранее выбранный системный сертификат (Windows/macOS). Если подходящих несколько — системный диалог выбора; дальше выбранный используется автоматически. Это поведение по умолчанию для `-windows`/`-macos`, если не указаны `-auto`/`-choose` |
| `-auto` | Автоматически выбранный сертификат из системного хранилища (нужен `-windows` или `-macos`) |
| `-choose` | Всегда показывать диалог выбора (нужен `-windows`/`-macos`; несовместим с `-auto`) |
| `-file <путь>` | Сертификат и приватный ключ из файла (игнорируется при `-none`) |
| `-pwd <пароль>` | Пароль файла сертификата (нужен `-file`) |
| `-none` | Клиентский сертификат не используется (соединение только с серверами, не требующими клиентского сертификата) |

Если не указан ни один из `-windows`, `-linux`, `-macos`, `-file`, `-none` — команда игнорируется.

### /HttpsCA — источник сертификатов ЦС

```
/HttpsCA [-windows] [-linux] [-macos] [-file <путь>] [-pwd <пароль>] [-none]
```

Логика та же, что у `/HttpsCert`: источник сертификатов удостоверяющих центров для проверки сертификата сервера. `-none` — корневые сертификаты не используются, сертификат сервера не проверяется.

### Принудительный протокол TLS

| Команда | Описание |
| --- | --- |
| `/HttpsForceTLS1_0` | Принудительно использовать TLS 1.0 |
| `/HttpsForceTLS1_1` | Принудительно TLS 1.1 или предшествующие версии |
| `/HttpsForceTLS1_2` | Принудительно TLS 1.2 или предшествующие версии |

Одновременное указание нескольких `/HttpsForce*` запрещено (поведение не определено). Без этих команд клиент пытается использовать TLS 1.3, понижая версию, если того требует веб-сервер.

## Вспомогательные параметры

| Команда | Описание |
| --- | --- |
| `/C <строка текста>` | Передача параметра в прикладное решение |
| `/ClearCache` | Очистка служебных данных в каталоге данных приложения: кеш клиент-серверных вызовов (подкаталог vrs-cache) и индекс поиска по текстам модулей (каталог cfg-cache; очищается, не удаляется). Каталог: Windows — `%LOCALAPPDATA%\1C\1cv8\<UUID DB>`; Linux/macOS — `~/.1cv8/1C/1cv8/<UUID DB>` |
| `/AllowExecuteScheduledJobs -Off\|-Force` | Управление регламентными заданиями. По умолчанию задания выполняются на первом запущенном клиенте без `-Off`; после завершения его сеанса — на другом запущенном сеансе. `-Off` — не выполнять на этом клиенте; `-Force` — выполнять на этом клиенте независимо от других сеансов |
| `/UC <код доступа>` | Установка соединения с базой, на которую установлена блокировка соединений (если при блокировке задан непустой код доступа) |
| `/RunShortcut <имя файла>` | Запуск со списком ИБ из файла: список общих ИБ (\*.v8i) или ярлык ИБ (\*.v8l) |
| `/AppAutoInstallLastVersion<режим>` | Автоустановка новых версий клиента: `+` — включена; `-` — выключена |
| `/Execute <имя файла внешней обработки>` | Запуск внешней обработки в режиме «1С:Предприятие» сразу после старта системы. Игнорирует `/URL`. Если параметры соединения не указаны — подключение к специальной базе EmptyIB в каталоге `<каталог ibases.v8i>/EmptyIB` (создается вместе с пустой базой, если отсутствует) |
| `/URL <адрес>` | Переход по ссылке (форматы e1c и http(s)). Подробности ниже |

### Как работает /URL

- **Внешняя ссылка** (содержит адрес ИБ): ищется запущенный клиент, обслуживающий эту базу (регистр имени хоста и ИБ не учитывается; преобразование DNS↔IP не выполняется — DNS-адрес и IP-адрес не совпадут; учитываются разделители из `/Z`). Найден и нет модального/блокирующего окна — клиент активизируется и выполняется переход по внутренней ссылке. Модальное окно открыто — клиент игнорируется, поиск продолжается. Не найден — запускается новый клиент с внутренней ссылкой (разделители передаются через `/Z`).
- **Внутренняя ссылка** — игнорируется, выполняется обычный запуск.
- Если ссылка содержит только адрес ИБ (например, `e1c://host/ib-name`) — после открытия клиента действий больше нет.
- Переход по внутренней ссылке: после обработчика ПриНачалеРаботыСистемы; в режиме «Формы в отдельных окнах» ссылка на точку навигации открывается вместо рабочего стола; при ошибке — диагностическое сообщение, приложение продолжает работу.
- Взаимодействие параметров: `/Execute` игнорирует `/URL`; абсолютная ссылка в `/URL` игнорирует `/F`, `/S`, `/WS`, `/IBName` и части строки соединения `/IBConnection`, описывающие ИБ.
- Схемы ссылок: `e1c:` — толстый и тонкий клиенты; `http:`/`https:` — только тонкий клиент.
- Эквиваленты: метод ПерейтиПоНавигационнойСсылке(), специальный диалог из окна списка ИБ, стандартная форма полнотекстового поиска (только `e1c:`).

## Прочие параметры

| Команда | Описание |
| --- | --- |
| `/@ <файл с командой>` | Взять командную строку из файла (обход ограничения длины командной строки ОС). Команда записывается целиком в одну строку; кодировка файла — кодировка командного интерпретатора. Содержимое файла **полностью заменяет** командную строку, поэтому `/@` должен быть первой (или единственной) командой; иначе поведение не определено |
| `/Out <имя файла> [-NoTruncate]` | Файл вывода служебных сообщений. `-NoTruncate` — не очищать файл (не для тонкого клиента). В пакетном режиме запись не буферизуется. Кодировка — UTF-8 |
| `/DisableStartupMessages` | Отключить стартовые сообщения («Конфигурация базы данных не соответствует сохраненной конфигурации. Продолжить?», сообщения о недостаточных возможностях компьютера для редактирования справки/html) |
| `/DisableStartupDialogs` | Отключить стартовый диалог и диалоги аутентификации. Ошибка, если: командной строки недостаточно для выбора ИБ/режима; недостаточно для авторизации пользователя; ошибочная авторизация в хранилище конфигурации; CREATEINFOBASE при заданном администраторе кластера. При отсутствии авторизации в хранилище Конфигуратор запускается без связи с ним. Поддерживается Конфигуратором, тонким и толстым клиентами. В клиенте включает [пакетный режим запуска клиентского приложения](07-client-batch-and-ole.md) |
| `/DisableSplash` | Отключить заставку при запуске (если она была полностью заменена) |
| `/DisableUnrecoverableErrorMessage` | Специальное поведение при невосстановимой ошибке (в т.ч. аварийном завершении): окно об ошибке не показывается; дамп формируется по logcfg.xml (Windows) или настройкам ОС (Linux/macOS); отчет об ошибке отправляется, если настроена автоотправка и размер ≤ 5 Мбайт; приложение завершается с ненулевым кодом. Рекомендуется для окружений без оператора |
| `/DisableHomePageForms` | Запретить открытие форм начальной страницы (тонкий клиент) |
| `/DisableLocalSpeechToText<режим>` | Локальное распознавание речи: `+` — запрещено; `-` — разрешено (по умолчанию); без значения — запрещено. Имеет приоритет над аналогичным параметром строки соединения |
| `/UseHwLicenses<режим>` | Поиск ключа защиты: `+` — выполняется; `-` — не выполняется |
| `/DisplayUserNotificationList` | Показывать непрочитанные сообщения системы взаимодействия и центра оповещений при старте клиента |
