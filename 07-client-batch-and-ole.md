## Пакетный режим запуска клиентского приложения

Пакетный режим — специальный режим, в котором платформа **не формирует диалоговых окон**. Действует от момента запуска до окончания выполнения обработчика события `ПередНачаломРаботыСистемы` модуля приложения. Обработчик `ПриНачалеРаботыСистемы` вызывается **после** завершения пакетного режима.

- Поддерживается **тонким и толстым** клиентскими приложениями.
- Активируется командой [`/DisableStartupDialogs`](02-common-parameters.md#интерфейс).
- **Веб-клиент не поддерживает** пакетный режим.
- После завершения пакетного режима работа приложения **не завершается автоматически**.
- Ошибки могут быть записаны в файл служебных сообщений ([`/Out`](02-common-parameters.md#прочие-параметры)).

### Особенности поведения

**Асинхронные методы:**

- Если во время пакетного режима вызывается асинхронный метод — он исполняется **после** обработчика `ПередНачаломРаботыСистемы`, но **до** завершения пакетного режима (при успешном запуске и открытии основного окна).
- Если пакетный режим завершился отказом от запуска (параметр `Отказ` обработчика `ПередНачаломРаботыСистемы` = `Истина`) — асинхронные вызовы **не исполняются**.

**Открытие окон запрещено.** При попытке:

- открытие формы блокируется;
- формируется ошибка.

Для определения запрета открытия окон предусмотрен метод глобального контекста `ЗапрещеноОткрытиеФорм()`.

**Внешние обработки:** запуск внешней обработки, переданной через [`/Execute`](02-common-parameters.md#прочие-параметры), выполняется **после** завершения пакетного режима.

**Запуск приложений:** если при выполнении `ЗапуститьПриложения()`/`НачатьЗапускПриложения()` обнаружена ошибка времени исполнения — в пакетном режиме формируется исключение.

## Регистрация OLE Automation

### /RegServer

```
/RegServer [-AllUsers | -CurrentUser | -Auto]
```

Регистрация объектов `V83.Application` и `V83C.Application`.

| Параметр | Поведение |
| --- | --- |
| `-AllUsers` | Регистрация для всех пользователей компьютера. Недостаточно прав — ошибка (в файл `/Out` или на экран) |
| `-CurrentUser` | Регистрация для текущего пользователя |
| `-Auto` | Для всех пользователей, если есть права; иначе — для текущего, без диалогов |
| *(без параметра)* | По привилегиям: есть права на весь компьютер — для компьютера; нет — вопрос о регистрации для текущего пользователя |

### /UnregServer

Отмена регистрации объектов `V83.Application` и `V83C.Application`.
