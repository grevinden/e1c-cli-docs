# Синтаксис командной строки и режимы запуска

← [К оглавлению](README.md) · Дальше: [Общие параметры](02-common-parameters.md)

## Общая форма

```
Приложение|URL [Режим] [Команда1 [Команда2 […]]]
```

- **Приложение** — имя (путь) запускаемого приложения. Особенности записи (полный путь, регистр) зависят от ОС и среды. Для веб-клиента роль «приложения» играет URL информационной базы, опубликованной на веб-сервере.
- **Режим** — необязательный параметр запуска некоторых приложений.
- **Команда** — определенное действие. У каждой команды есть обязательные и необязательные параметры, а также необязательное значение. Можно ли комбинировать несколько команд в одной строке — зависит от приложения, режима и самих команд; некоторые команды взаимоисключающи.

## Соглашения об обозначениях

| Символ | Значение |
| --- | --- |
| Пробел | Разделитель всех элементов командной строки |
| `/` | Начало команды (исключение — веб-клиент: команды не предваряются `/` и разделяются символом `&`) |
| `-` | Начало параметра команды |
| `[...]` | Необязательный элемент |
| `\|` | Разделяет взаимоисключающие варианты (используется только один) |
| `<...>` | Краткое описание значения параметра; в реальную командную строку не переносится |

Важно: в большинстве командных интерпретаторов `<` и `>` означают переадресацию потоков ввода/вывода — буквальный перенос этих символов радикально меняет смысл команды.

Значения могут быть не только у команд, но и у параметров команд. Если значение содержит пробелы, заключайте его в кавычки: символ `"` внутри значения пишется как `\"`, а `\` перед `"` — как `\\`.

### Как читать описания команд

```
/TComp [-None|-Deflate|-SDC|-lz4|-zstd]
```

Команда `TComp` с необязательным выбором одного из пяти параметров; допустимо указать `/TComp` без параметров.

```
/VA<режим>
```

Команда `VA` со значением `<режим>`, указываемым без пробела после команды.

```
/MergeCfg <имя cf-файла> -Settings <имя файла настроек> [-EnableSupport | -DisableSupport] [-IncludeObjectsByUnresolvedRefs | -ClearUnresolvedRefs] [-force]
```

Состав: обязательный параметр `<имя cf-файла>`; обязательный параметр `Settings` со своим значением; две группы взаимоисключающих необязательных параметров; необязательный флаг `force`.

## Три стиля записи параметров

В зависимости от утилиты используется один из стилей:

| Стиль | Команда | Параметр | Где применяется |
| --- | --- | --- | --- |
| 1 | `/Команда` | `-Параметр` | 1cv8 (пакетный Конфигуратор), ragent (сервер) |
| 2 | `Команда` | `--полное-имя` / `-сокращенное` | ring |
| 3 | `--Команда` / `-Сокращение` | — | cnvdbfl |

В документации для каждого приложения сначала приводится общая форма командной строки — по ней понятно, какой стиль используется.

## Режимы запуска

Одновременное использование нескольких режимов не допускается.

### Режим 1С:Предприятие

```
1cv8 ENTERPRISE [<параметры запуска>]
```

Используются [общие параметры запуска](02-common-parameters.md).

### Режим Конфигуратора

```
1cv8 DESIGNER [<команды>]
```

Команды включают:

- [общие команды запуска](02-common-parameters.md);
- один из наборов:
  - [команды пакетного запуска Конфигуратора](03-configurator-batch.md);
  - [команды создания файлов поставки и обновления](04-configurator-batch-advanced.md#файлы-поставки-и-обновления);
  - [команды работы с хранилищем конфигурации](05-configuration-repository.md);
  - [регистрация OLE Automation](07-client-batch-and-ole.md#регистрация-ole-automation).

### Режим создания информационной базы

```
1cv8 CREATEINFOBASE <строка соединения> [/AddToList [<имя ИБ>]] [/UseTemplate <имя файла шаблона>] [/Out <имя файла>] [/L<код языка>] [/VL<код локализации>] [/O<скорость соединения>] [/DumpResult <имя файла>]
```

| Параметр | Описание |
| --- | --- |
| `<строка соединения>` | Строка, задающая параметры доступа к базе данных — [подробнее](08-connection-string.md) |
| `/AddToList [<имя ИБ>]` | Добавить созданную базу в список баз (под указанным или именем по умолчанию). Без параметра база в список не добавляется |
| `/UseTemplate <имя файла шаблона>` | Создавать базу по шаблону: файл конфигурации (.cf) или файл выгрузки базы (.dt) |
| `/L<код языка>` | Код языка интерфейса платформы |
| `/VL<код локализации>` | Код локализации сеанса (форматирование типов Число и Дата, методы ЧислоПрописью() и ПредставлениеПериода()) |
| `/O<скорость соединения>` | Скорость соединения: `Normal` / `Low` |
| `/Out <имя файла>` | Файл вывода служебных сообщений |
| `/DumpResult <имя файла>` | Записать результат создания базы в файл (0 — успех) |
