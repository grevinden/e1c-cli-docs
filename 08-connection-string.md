# Строка соединения с информационной базой

← [К оглавлению](README.md) · Назад: [Пакетный клиент и OLE](07-client-batch-and-ole.md) · Дальше: [Веб-клиент](09-web-client.md)

Строка соединения задаёт параметры информационной базы. Каждый параметр — фрагмент вида `<Имя>=<Значение>`, фрагменты разделяются `;`. Значения с пробелами заключаются в двойные кавычки.

Набор параметров зависит от варианта базы (файловый / клиент-серверный) + общий набор для обоих.

Где используется:

- форма списка информационных баз (под списком);
- параметр командной строки режима [`CREATEINFOBASE`](01-syntax-and-modes.md#режим-создания-информационной-базы);
- параметр метода `СоздатьНачальныйОбраз()`.

## Общий набор параметров

| Параметр | Описание |
| --- | --- |
| `Usr` | Имя пользователя |
| `Pwd` | Пароль пользователя |
| `LicDstr` | Получение клиентских лицензий через сервер «1С:Предприятия»: `Y` — получать (если не получена из локального/сетевого ключа HASP); `N` — не получать (по умолчанию) |
| `Z n` | Установка значений разделителей прикладного решения |
| `prmod` | Запуск в привилегированном режиме (значение `1`). Разрешён пользователю с административными правами. Журнал регистрации фиксирует установку или отказ |
| `disstt` | Локальное распознавание речи: `Y` — запрещено; `N` — разрешено (по умолчанию). Влияет на установку запрета при создании клиент-серверной базы; при использовании параметра запрет устанавливается при подключении к файловой базе (в т.ч. со стороны расширения веб-сервера или через COM) |

## Файловый вариант

| Параметр | Описание |
| --- | --- |
| `File` | Каталог размещения файла базы данных |
| `Locale` | Язык (страна) при открытии/создании. Допустимые значения — как у `<Форматная строка>` метода `Формат()`. Необязательно: по умолчанию — региональные установки текущей базы |
| `DBFormat` | Формат создаваемой базы: `8.2.14` (по умолчанию) или `8.3.8` |
| `DBPageSize` | Размер страницы для формата `8.3.8`: `4096`/`4k` (по умолчанию), `8192`/`8k`, `16384`/`16k`, `32768`/`32k`, `65536`/`64k` |

## Клиент-серверный вариант

| Параметр | Описание |
| --- | --- |
| `Srvr` | Адрес сервера: `[<протокол>://]<адрес>[:<порт>]`. Протокол — только TCP (не обязателен); адрес — имя или IPv4/IPv6; порт главного менеджера кластера (по умолчанию **1541**) |
| `Ref` | Имя базы данных на сервере «1С:Предприятия» |
| `DBMS` | Тип СУБД: `MSSQLServer`, `PostgreSQL`, `IBMDB2`, `OracleDatabase` |
| `DBSrvr` | Имя сервера баз данных |
| `DB` | Имя базы данных в СУБД |
| `DBUID` | Пользователь СУБД |
| `DBPwd` | Пароль пользователя СУБД (можно опустить, если пароль не задан) |
| `SQLYOffs` | Смещение дат для Microsoft SQL Server: `0` (по умолчанию) или `2000` |
| `Locale` | Язык (страна) — аналогично файловому варианту |
| `CrSQLDB` | Создавать СУБД при отсутствии: `Y` / `N` (по умолчанию) |
| `SchJobDn` | Запрет регламентных заданий в созданной базе: `Y` — блокировка включена; `N` — выключена (по умолчанию) |
| `SUsr` | Администратор кластера для создания начального образа (нужен, если в кластере определены администраторы и аутентификация ОС для них не установлена/не подходит) |
| `SPwd` | Пароль администратора кластера |

### Несколько адресов кластера

Для бесперебойной работы можно указать несколько адресов кластера:

- значение `Srvr` — список адресов через запятую (**пробелы недопустимы**);
- в диалоге добавления базы — свойство «Кластер серверов 1С:Предприятия» принимает список через запятую.

Примеры `Srvr`:

| Значение | Что задано |
| --- | --- |
| `server` | Имя сервера, остальное по умолчанию |
| `tcp://server:1641` | Протокол, имя, порт |
| `127.0.0.1:1541` | IPv4 + порт |
| `[fe10::c47b:90b7:fa32:a2fa%12]` | IPv6, протокол и порт по умолчанию |
