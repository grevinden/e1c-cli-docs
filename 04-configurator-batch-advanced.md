## Проверки конфигурации и расширений

### /CheckModules — проверка программных модулей

```
/CheckModules [-ThinClient] [-WebClient] [-MobileClient] [-MobileClientStandalone] [-MobileAppClient]
              [-Server] [-MobileAppServer] [-ExternalConnection] [-ThickClientOrdinaryApplication]
              [-ExtendedModulesCheck] [-Extension <имя>] [-AllExtensions]
```

Нужен хотя бы один параметр режима, иначе проверка не выполняется.

| Параметр | Режим проверки |
| --- | --- |
| `-ThinClient` | Тонкий клиент |
| `-WebClient` | Веб-клиент |
| `-MobileClient` | Мобильный клиент |
| `-MobileClientStandalone` | Мобильный клиент в автономном режиме |
| `-MobileAppClient` | Клиент мобильного приложения |
| `-Server` | Сервер «1С:Предприятия» |
| `-MobileAppServer` | Сервер мобильного приложения |
| `-ExternalConnection` | Внешнее соединение |
| `-ThickClientOrdinaryApplication` | Клиентское (обычное) приложение |
| `-ExtendedModulesCheck` | Проверка обращений «через точку» (ограниченный набор типов) и правильности строковых литералов параметров функций вроде ПолучитьФорму() |
| `-Extension` / `-AllExtensions` | Для указанного / всех расширений |

### /CheckConfig — централизованная проверка конфигурации

```
/CheckConfig [-ConfigLogIntegrity] [-IncorrectReferences] [-ThinClient] [-WebClient] [-MobileClient]
             [-MobileClientStandalone] [-MobileAppClient] [-MobileAppServer] [-Server]
             [-ExternalConnection] [-ExternalConnectionServer] [-ThickClientManagedApplication]
             [-ThickClientServerManagedApplication] [-ThickClientOrdinaryApplication]
             [-ThickClientServerOrdinaryApplication] [-DistributiveModules] [-UnreferenceProcedures]
             [-HandlersExistence] [-EmptyHandlers] [-ExtendedModulesCheck] [-CheckUseModality]
             [-CheckUseSynchronousCalls] [-UnsupportedFunctional] [-MobileClientDigiSign]
             [-Extension <имя>] [-AllExtensions]
```

| Параметр | Что проверяется |
| --- | --- |
| `-ConfigLogIntegrity` | Логическая целостность конфигурации (стандартная проверка перед обновлением базы) |
| `-IncorrectReferences` | Некорректные ссылки: на удаленные объекты (по всей конфигурации, включая права, формы, макеты, интерфейсы) и логически неправильные |
| `-ThinClient` … `-ThickClientServerOrdinaryApplication` | Синтаксический контроль модулей в эмуляции соответствующей среды (тонкий/веб/мобильный клиент, сервер, внешнее соединение в файловом и клиент-серверном режимах, толстый клиент в управляемом/обычном режиме) |
| `-DistributiveModules` | Возможность генерации образов модулей, поставляемых без исходных текстов |
| `-UnreferenceProcedures` | Неиспользуемые локальные (не экспортные) процедуры/функции, включая обработчики событий |
| `-HandlersExistence` | Существование назначенных обработчиков (интерфейсы, формы, элементы управления) |
| `-EmptyHandlers` | Пустые обработчики событий (могут снижать производительность) |
| `-ExtendedModulesCheck` | Обращения «через точку» и строковые литералы (см. `/CheckModules`) |
| `-CheckUseModality` | Поиск методов, связанных с модальностью (только с `-ExtendedModulesCheck`) |
| `-CheckUseSynchronousCalls` | Поиск синхронных методов (только с `-ExtendedModulesCheck`) |
| `-UnsupportedFunctional` | Функциональность, недоступная на мобильной платформе: нереализованные классы метаданных; планы обмена с РИБ; нереализованные типы (реквизиты, константы, параметры сеанса, параметры команд, реквизиты/колонки форм); формы типа «Обычная»; нереализованные элементы управления (кроме форм без назначения для мобильного устройства); рабочий стол из более чем одной формы |
| `-MobileClientDigiSign` | Цифровая подпись конфигурации мобильного клиента |
| `-Extension` / `-AllExtensions` | Для указанного / всех расширений |

### /CheckCanApplyConfigurationExtensions — применимость расширений

```
/CheckCanApplyConfigurationExtensions [-Extension <имя>] [-AllZones] [-Z "значения разделителей"]
```

Проверка применимости расширения для конкретной базы.

| Параметр | Описание |
| --- | --- |
| `-Extension <имя>` | Проверить указанное расширение с учетом всех ранее загружаемых; без имени — все расширения в порядке загрузки |
| `-AllZones` | Проверить во всех областях данных текущей базы. Несовместим с `-Extension` и `-Z` |
| `-Z` | Значения разделителей для проверки (без параметра — область без установленных разделителей) |

Результат для каждой области предваряется `-Z` с ее разделителями. Если указаны и `/Z` (запуск), и `-Z` (параметр команды): `/Z` — для запуска и выбора пользователя, `-Z` — для области данных проверки.

### /IBCheckAndRepair — тестирование и исправление базы

```
/IBCheckAndRepair [-ReIndex] [-LogIntegrity [таблицы]] [-LogAndRefsIntegrity [таблицы]] [-RecalcTotals]
                  [-IBCompression] [-Rebuild] [-RebuildStandaloneCfg] [-RebuildConfigurationExtension]
                  [-Z: "разделители"] [-ConfigurationExtensionsLogIntegrity]
                  [-TestOnly | [[-BadRefCreate | -BadRefClear | -BadRefNone] [-BadDataCreate | -BadDataDelete]]]
                  [-UseStartPoint] [-TimeLimit:hhh:mm] [-RefreshTableLocation]
                  [-BinaryDataStorageIntegrity [таблицы]] [-JobsCount <N>] [-CheckAndEnableCORPFunctionality]
```

| Параметр | Описание |
| --- | --- |
| `-ReIndex` | Реиндексация таблиц |
| `-LogIntegrity [таблицы]` | Проверка логической целостности (без значения — все таблицы) |
| `-LogAndRefsIntegrity [таблицы]` | Проверка логической и ссылочной целостности |
| `-RecalcTotals` | Пересчет итогов |
| `-IBCompression` | Сжатие таблиц (для файлового варианта — плюс специальная оптимизация) |
| `-Rebuild` | Реструктуризация таблиц базы |
| `-RebuildStandaloneCfg` | Пересоздать конфигурацию мобильного клиента с автономным режимом |
| `-RebuildConfigurationExtension` | Реструктуризация таблиц расширений (без монопольного доступа, если указан только этот параметр) |
| `-Z: "разделители"` | Тестирование/исправление расширений в указанных областях (несколько раз — несколько областей). Несовместима с `/Z` |
| `-ConfigurationExtensionsLogIntegrity` | Проверка (и исправление, если возможно) логической целостности расширений; с `-TestOnly` — только проверка. Без монопольного доступа, если указан только этот параметр |
| `-TestOnly` | Только тестирование, без исправления |
| `-BadRefCreate` / `-BadRefClear` / `-BadRefNone` | При ссылках на несуществующие объекты: создавать / очищать / не изменять (только без `-TestOnly`) |
| `-BadDataCreate` / `-BadDataDelete` | При частичной потере информации об объектах: создавать / удалять (только без `-TestOnly`) |
| `-UseStartPoint` | Продолжить с сохраненной точки возврата (если предыдущий сеанс прервался) |
| `-TimeLimit:hhh:mm` | Ограничение времени сеанса (часы 0…999, минуты 0…59). Прерывание — только когда возможно, не точно по таймеру |
| `-RefreshTableLocation` | Обновить информацию о расположении таблиц в пользовательских табличных пространствах |
| `-BinaryDataStorageIntegrity [таблицы]` | Проверка целостности хранилища двоичных данных |
| `-JobsCount <N>` | Число фоновых заданий (0 = по ядрам; 1 = без параллелизма). Максимальное ускорение — кластер и СУБД на одной машине, канал ≥ 1 Гбит |
| `-CheckAndEnableCORPFunctionality` | Проверка и актуализация базы в зависимости от настроек CORP |

Параметры внутри подгруппы (`-BadRef*`, `-BadData*`) одновременно не используются.

Список допустимых таблиц для `-LogIntegrity`, `-LogAndRefsIntegrity`, `-BinaryDataStorageIntegrity` (через запятую):

| Объект | Значение |
| --- | --- |
| Бизнес-процессы | `BusinessProcesses` |
| Документы | `Documents` |
| Другие объекты | `Other` |
| Журнал документов | `DocumentJournals` |
| Задачи | `Tasks` |
| Константы | `Constants` |
| Планы видов расчета | `ChartsOfCalculationTypes` |
| Планы видов характеристик | `ChartsOfCharacteristicTypes` |
| Планы обмена | `ExchangePlans` |
| Планы счетов | `ChartsOfAccounts` |
| Регистры бухгалтерии | `AccountingRegisters` |
| Регистры накопления | `AccumulationRegisters` |
| Регистры расчета | `CalculationRegisters` |
| Регистры сведений | `InformationRegisters` |
| Справочники | `Catalogs` |

## Поддержка конфигурации

### /UpdateCfg — обновление конфигурации на поддержке

```
/UpdateCfg <имя cf или cfu файла> -Settings <файл настроек>
           [-IncludeObjectsByUnresolvedRefs | -ClearUnresolvedRefs]
           [-DumpListOfTwiceChangedProperties] [-force]
```

Объединение текущей конфигурации (находящейся на поддержке) с файлом конфигурации (.cf) или файла обновления (.cfu) по файлу настроек.

| Параметр | Описание |
| --- | --- |
| `-IncludeObjectsByUnresolvedRefs` / `-ClearUnresolvedRefs` | То же, что в [`/MergeCfg`](03-configurator-batch.md#объединение-конфигураций) |
| `-DumpListOfTwiceChangedProperties` | Вывести список дважды измененных свойств в файл сообщений |
| `-force` | Продолжать при: предупреждениях об удаляемых объектах со ссылками; дважды измененных свойствах без выбранного режима (объединяются с настройками по умолчанию); объектах, изменение которых запрещено правилами поддержки (исключаются); предупреждениях о применении настроек |

Предупреждения о дважды измененных свойствах выводятся независимо от `-force`.

### /ManageCfgSupport — снятие с поддержки

```
/ManageCfgSupport [-disableSupport [-force]]
```

| Параметр | Описание |
| --- | --- |
| `-disableSupport` | Снять конфигурацию с поддержки (без параметра — ошибка) |
| `-force` | Снять даже если в конфигурации запрещены изменения (без флага — ошибка) |

## Файлы поставки и обновления

### /CreateTemplateListFile

```
/CreateTemplateListFile <имя файла> [-TemplatesSourcePath <путь>]
```

Создать файл списка шаблонов конфигураций. `-TemplatesSourcePath` — путь поиска шаблонов (по умолчанию — путь из настроек диалога при запуске).

### /CreateDistributivePackage

```
/CreateDistributivePackage <каталог> -File <файл описания комплекта> -PackageFileName <имя архива>
                           [-Option <вариант поставки>] [-MakeSetup] [-MakeFiles]
                           [-digisign <файл параметров лицензирования>] [-WarningAsError]
```

Создание архива комплекта поставки или файлов комплекта по готовому описанию. Если задана подпись мобильного клиента — проверяется соответствие подписи текущим метаданным (несоответствие — диагностическое сообщение; с `-WarningAsError` — ошибка и прерывание).

| Параметр | Описание |
| --- | --- |
| `-File <файл>` | Файл описания комплекта поставки |
| `-PackageFileName <архив>` | Имя zip-архива (создается в каталоге; расширение .zip добавляется автоматически; по умолчанию `updsetup.zip`). Только с `-MakeSetup` |
| `-Option <вариант>` | Вариант поставки (по умолчанию «Полный») |
| `-MakeSetup` / `-MakeFiles` | Комплект поставки / файлы комплекта (только один; без параметров — `-MakeSetup`) |
| `-digisign <файл>` | Параметры лицензирования рабочего места |
| `-WarningAsError` | Несоответствие подписи мобильного клиента — ошибка |

### /CreateDistributionFiles

```
/CreateDistributionFiles [-cffile <имя cf-файла>] [-cfufile <имя cfu-файла> [-f <имя cf-файла>|-v <версия>]+]
                         [-digisign <файл>] [-WarningAsError]
```

Создание файлов поставки и обновления. Группа `-f`/`-v` повторяется по числу дистрибутивов, включаемых в обновление. Проверка подписи мобильного клиента — как в `/CreateDistributivePackage`.

### /CreateDistributive — устаревшая

```
/CreateDistributive <каталог> -File <файл описания> [-Option <вариант>] [-MakeSetup] [-MakeFiles]
                     [-digisign <файл>] [-WarningAsError]
```

> Устаревшая команда, не рекомендуется к использованию. Параметры аналогичны `/CreateDistributivePackage` (без `-PackageFileName`).

### /SignCfg — подпись расширения

```
/SignCfg -ConfigurationType <тип> -SignedFile <путь к cfe-файлу> [-File <путь к cfe-файлу>]
         [-Name <имя расширения>] [-Version <версия>] -digisign <файл параметров лицензирования>
```

Подписать расширение цифровой подписью. После подписи расширение может использоваться в базовых конфигурациях, подписанных тем же ключом.

| Параметр | Описание |
| --- | --- |
| `-ConfigurationType <тип>` | `ExtensionConfiguration` — расширение; `ExtensionDBConfiguration` — расширение из базы; `ExtensionConfigurationRepository` — расширение из хранилища; `File` — файл расширения |
| `-SignedFile <путь>` | Результирующий подписанный файл |
| `-File <путь>` | Подписываемый файл (для типа `File`) |
| `-Name <имя>` | Имя расширения (для типов Extension*/ExtensionDB*/ExtensionConfigurationRepository) |
| `-Version <версия>` | Версия в хранилище (для `ExtensionConfigurationRepository`) |
| `-digisign <файл>` | Параметры лицензирования |

## Внешние обработки (отчеты)

Важно: если внешняя обработка (отчет) содержит ссылки на объекты конфигурации, при выгрузке в XML типы ссылок записываются как уникальные идентификаторы. Корректное восстановление типов при загрузке возможно только в ту же конфигурацию или в ее потомка. Чтобы избежать проблемы, выгрузку и загрузку выполняйте **с параметрами подключения к базе** в командной строке — тогда в файлы подставляются текстовые представления типов. При загрузке тоже укажите параметры базы, иначе информация о типах потеряется. Если ссылок на объекты конфигурации нет — параметры подключения не нужны.

### /DumpExternalDataProcessorOrReportToFiles

```
/DumpExternalDataProcessorOrReportToFiles <корневой каталог выгрузки> <путь к .epf/.erf> [-Format Plain|Hierarchical]
```

Выгрузка внешней обработки (отчета) в XML (формат 2.0). `-Format`: `Plain` — линейный; `Hierarchical` — иерархический (по умолчанию).

### /LoadExternalDataProcessorOrReportFromFiles

```
/LoadExternalDataProcessorOrReportFromFiles <корневой каталог> <путь к .epf/.erf>
```

Загрузка из XML (формат 2.0). Расширение результирующего файла определяется автоматически по XML-файлам (неверное расширение в командной строке заменяется).

## Мобильное приложение и мобильный клиент

| Команда | Описание |
| --- | --- |
| `/MobileAppUpdatePublication` | Обновить публикацию мобильного приложения (если она создана; иначе — ошибка). Возможно предварительное обновление конфигурации базы |
| `/MobileAppWriteFile <имя zip-файла>` | Сохранить конфигурацию в zip-файл для сборки приложения: XML-описание конфигурации + файл данных для создания базы на устройстве |
| `/MobileClientWriteFile <имя файла>` | Сохранить конфигурацию в файл для сборки мобильного клиента. Возможно предварительное обновление конфигурации базы |
| `/MobileClientDigiSign` | Подписать конфигурацию мобильного клиента. Возможно предварительное обновление конфигурации базы |

## Журнал регистрации

`/ReduceEventLogSize <Дата> [-saveAs <имя файла>] [-KeepSplitting]` — сокращение журнала регистрации.

| Параметр | Описание |
| --- | --- |
| `<Дата>` | Новая граница журнала в формате ГГГГ-ММ-ДД |
| `-saveAs <файл>` | Сохранить копию выгружаемых записей |
| `-KeepSplitting` | Сохранить разделение на файлы по периодам |

## Удаление данных

`/EraseData [/Z[<разделители>]]` — удаление данных информационной базы. `/Z` задает область удаления. Требуется право «Администрирование».

## Предопределенные данные

`/SetPredefinedDataUpdate [-Auto] [-UpdateAutomatically] [-DoNotUpdateAutomatically]` — режимы обновления предопределенных данных при реструктуризации.

| Параметр | Описание |
| --- | --- |
| `-Auto` | Вычислять автоматически (по умолчанию): главный узел ИБ — как `-UpdateAutomatically`, периферийный — как `-DoNotUpdateAutomatically` |
| `-UpdateAutomatically` | При реструктуризации автоматически создавать предопределенные элементы и обновлять значения |
| `-DoNotUpdateAutomatically` | При реструктуризации не создавать и не обновлять |

## Распределенная информационная база

`/ResetMasterNode` — отменить назначение главного узла РИБ (аналог метода УстановитьГлавныйУзел() со значением Неопределено).
