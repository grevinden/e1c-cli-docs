# 1С:Предприятие 8.3 — интерфейс командной строки

Структурированный справочник по командной строке платформы «1С:Предприятие», составленный по официальной документации (версия 8.3.26, Приложение 7 «Параметры командной строки запуска «1С:Предприятия»»).

Командная строка позволяет:

- запускать платформу в разных режимах (приложение, Конфигуратор, создание базы данных);
- выполнять пакетные операции (выгрузка/загрузка базы, обновление конфигурации, проверки, создание файлов поставки);
- работать с хранилищем конфигурации;
- настраивать запуск клиентских приложений (аутентификация, сертификаты, отладка, тестирование).

## Общий синтаксис

```
Приложение|URL [Режим] [Команда1 [Команда2 […]]]
```

- **Приложение** — путь к исполняемому файлу (для веб-клиента — URL опубликованной базы данных).
- **Режим** — необязательный режим запуска (см. ниже).
- **Команда** — действие с обязательными и необязательными параметрами.

Элементы разделяются пробелом. Значения с пробелами заключаются в кавычки (внутри кавычек `"` записывается как `\"`, а `\` перед `"` — как `\\`).

Подробности синтаксиса и соглашения об обозначениях — в [01-syntax-and-modes.md](01-syntax-and-modes.md).

## Режимы запуска

| Режим | Назначение | Пример |
| --- | --- | --- |
| `ENTERPRISE` | Запуск приложения «1С:Предприятие» | `1cv8 ENTERPRISE /F "C:\Bases\Demo"` |
| `DESIGNER` | Запуск Конфигуратора (в т.ч. пакетный режим) | `1cv8 DESIGNER /IBName "My db" /DumpIB c:\temp\dump.dt` |
| `CREATEINFOBASE` | Создание новой информационной базы | `1cv8 CREATEINFOBASE "File=C:\Bases\New" /AddToList` |

Одновременно может быть указан только один режим.

## Коды возврата

В пакетном режиме:

- `0` — ошибок нет;
- `1` — есть ошибки (текст ошибки выводится в файл служебных сообщений, задаваемый параметром `/Out`).
